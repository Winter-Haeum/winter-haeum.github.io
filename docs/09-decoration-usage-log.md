# 데코 에셋 사용 기록표

## 1. 문서 목적

이 문서는 `/images/decoration/` 경로의 데코 에셋이 챕터별로 어떻게 사용되고 있는지 기록한 참고표입니다.

- **목적**: 같은 데코 파일이 여러 챕터에 반복 사용되는 문제를 줄이기 위함
- **활용법**: 새 챕터 데코 작업 전, 이 문서에서 자주 쓰인 파일을 확인하고 덜 쓰인 파일을 우선 검토
- **조사 범위**: setup/step-01~05, lesson-1(1-1~1-5), lesson-2(2-1~2-6), lesson-3(3-1~3-4), JavaScript Basics(JS-1-1~JS-1-4)
- **조사 기준**: 실제 코드 내 `src="/images/decoration/..."` 또는 `src="/images/character/..."` 속성 기준 집계

**챕터 약칭 정의**

| 약칭 | 파일 |
|------|------|
| S01~S05 | setup/step-01 ~ step-05 |
| 1-1~1-5 | lesson-1 챕터 |
| 2-1~2-6 | lesson-2 챕터 |
| 3-1~3-4 | lesson-3 챕터 |
| JS-1-1~JS-1-3 | javascript/basics/1-1 ~ 1-3 |

**크기 기준**: S(≤42px) / M(43–55px) / L(56–72px) / XL(73px 이상)

## 5. 다음 챕터 수정 시 참고 규칙

1. **자주 사용된 데코 우선 제외**
   - 특히 `별 아이콘 (3)(5)(7)(8)(11)`, `반짝이 아이콘 (2)(3)(4)(5)`, `마스킹 테이프 (7)(9)(11)`, `책갈피 아이콘 (2)`, `체크 아이콘 (2)`는 당분간 배치 금지

2. **거의 사용하지 않은 데코를 우선 검토**
   - 느낌표, 말풍선, 스탬프, 소품, 잎사귀 (1), 구름 (3)(5) 계열 먼저 사용 검토

3. **같은 종류 데코 반복 사용 금지**
   - 한 챕터 내에서 같은 번호의 파일명을 2회 이상 사용하지 않음

4. **별 아이콘 크기 규칙**
   - 별 아이콘은 반드시 L(56–72px) 또는 XL(73px 이상) 크기로만 사용
   - S/M 크기의 별 아이콘은 신규 배치 금지 (기존 파일 수정 대상 아님)

5. **느낌표 아이콘 크기 규칙**
   - 느낌표 아이콘은 M(43–55px) 기준으로 사용

6. **배치 방식**
   - 데코는 기본적으로 `position:absolute` overlay 방식으로 배치
   - 제목 옆 배치: heading 아래 `height:0;overflow:visible` div 패턴 사용
   - 박스 내부 배치: 부모에 `position:relative;overflow:visible` 필수

7. **구분선(---) 위 배치 제한**
   - 챕터 전체에서 구분선 위 데코는 1–2개 이하로 유지

8. **연속 배치 금지**
   - 같은 height:0 div에 데코 2개 이상 금지
   - y축 차이 40px 미만의 데코 나란히 배치 금지
