## 6. 참고 사항

아래 항목은 v1 완성 차단 요소로 보지 않는다.

### 방문자 카운터

헤더 방문자 집계가 일부 자동 점검 시점에서 `집계 준비 중`으로 보일 수 있다.

다만 실제 화면에서 방문자 카운터가 정상 표시되는 경우가 있으며, 이는 v1 완성을 막는 핵심 결함이 아니라 Supabase 응답 타이밍 또는 부가 기능의 상태로 분류한다.

### 검색 결과 범위

`React`처럼 넓은 단어를 검색할 경우 결과가 많이 나올 수 있다.

이는 Fuse.js 기반 검색의 퍼지 매칭 특성으로 보고, v1 완성 차단 요소로 보지 않는다. 검색 정확도 개선은 향후 개선 후보로 둔다.

## 8. README 작성 보류 사유

README는 v1 완성 직후 바로 작성하지 않는다.

이 프로젝트는 Vibe Coding을 통해 구현된 부분이 많기 때문에, 사용자가 실제 코드 구조와 웹 동작 방식을 공부한 뒤 자신의 이해와 의견을 반영해 작성하는 것이 더 적절하다.

따라서 README는 v1 완성 직후 산출물이 아니라, 프로젝트 구조 학습 이후 작성할 후속 산출물로 둔다.
